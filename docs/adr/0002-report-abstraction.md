# 0002. Аналитика через сменные отчёты; виджет графика — только отображение

## Контекст

Один и тот же срез данных можно представлять по-разному (макс. вес; вес + повторы; объём; вес тела относительно тренировок; данные по мышцам), и набор метрик будет расширяться. Если зашить линии графика в виджет, он окажется связан с конкретными метриками и не переиспользуем для веса тела и мышц.

## Решение

Виджет графика — чистое отображение. Логика метрик вынесена в подключаемую стратегию **Отчёт** (Report), которая знает:

- число линий и их подписи;
- максимум шкалы для линии;
- флаг «раздельные графики стопкой ↔ все линии на одной оси»;
- вычисление значения линии по точке данных.

Точки данных произвольны (день упражнения, вес тела + тренировка, данные мышцы) — под каждый вид данных свои реализации отчётов. Пользователь выбирает отчёт при открытом графике.

## Рассмотренные альтернативы

- **Хардкод трёх линий (вес/повторы/сеты) в виджете** — проще, но не расширяемо и не переиспользуемо для веса тела и мышц.

## Последствия

- Новая метрика = новая реализация отчёта, без правок виджета.
- Фаза 1 — интерфейс отчёта + 1–2 встроенных (макс. вес; макс. вес + повторы при нём). Вес тела, флаг раздельных графиков, режим «за всё время», зум — Фаза 2.
