# 0004. Сессия: ручное завершение блока, персистентный таймер, авто-восстановление

## Контекст

Фаза 1 реализовала сессию с **авто-завершением** блока по достижении целевого числа сетов и с состоянием таймера **в React-компоненте**. Живое тестирование показало: (1) пользователь хочет сам решать, делать ли ещё сет или закончить; (2) закрытие вкладки/сон телефона/переход в YouTube за видео упражнения теряют таймер, а Home показывает «начать» при живой сессии. Оба поведения выглядят «естественно» с точки зрения кода и будут воспроизведены агентом заново, если не зафиксировать обратное.

## Решение

### 1. Сессия — единственный носитель активной тренировочной активности

- Любая активность с упражнением — это **Сессия** в сейве: плановая (снимок тренировки) **или внеплановая без плана** (одно упражнение по кнопке «+» вне тренировки). Раньше внеплановое вне тренировки писало результаты напрямую в историю без сессии — это убрано, чтобы таймер и восстановление работали одинаково.
- Сессия хранит **состояние таймера**: `endAt` (абсолютная метка), базовую длительность, признак «идёт/стоит». Состояние таймера в UI-компоненте — **только отображение**, не источник истины.

### 2. Завершение блока — только вручную

- Панель ввода имеет две кнопки: **«добавить»** (записать сет) и **«завершить»** (закрыть блок).
- «Добавить» **никогда** не завершает блок автоматически, сколько бы сетов ни было записано.
- «Завершить» закрывает **весь блок** (все упражнения суперсета разом).
- Кнопка «завершить» **мигает**, когда каждое упражнение блока достигло целевого числа сетов; это подсказка, не действие.
- В суперсете все упражнения имеют **одно** число сетов (свойство блока). Сеты сверх цели продолжают чередование A→B→A→B целыми раундами. Если одному упражнению нужны дополнительные подходы — это отдельный блок после суперсета, не исключение в модели.
- Удаление сета **откатывает** счётчик «сет N/M» и курсор внутри блока.
- «Завершить» на **последнем** блоке завершает сессию → расписание продвигается ровно один раз → экран результата. Отдельной кнопки «завершить тренировку» нет.
- Внеплановое упражнение: «завершить» возвращает к таймлайну плановой сессии (если она есть) или на Home; курсор расписания не двигается.

### 3. Таймер: отсчёт от `endAt`, перерасход отрицательным временем

- Отсчёт — от абсолютной метки `endAt` через порт `Clock`; никаких накопительных интервалов.
- По достижении `endAt` таймер **не останавливается**: продолжает тикать в **отрицательную** сторону (`-0:01`, `-0:02`, … `-5:00`). Это показывает, насколько затянулся отдых.
- **Тап по таймеру** во время отсчёта или перерасхода — останавливает и возвращает к **базовому значению** (предзаполненный интервал текущего места с учётом ручной докрутки, например `1:30`).
- Звук + вибрация — один раз в момент `endAt`, если страница жива. Докрутка `±` во время отсчёта сдвигает `endAt` и перепланирует сигнал.
- Базовое значение вне плана (внеплановое упражнение без тренировки) — настройка «интервал между подходами по умолчанию».
- Wake-lock удерживает экран, пока открыт экран тренировки с таймером.

### 4. Восстановление при открытии приложения

Открытие приложения (запуск PWA, восстановление вкладки, возврат из фона с выгрузкой страницы) при наличии сессии в сейве:

- **Порог N часов не превышен и сутки не сменились** (граница суток — ADR 0001, «начало суток») → **сразу экран тренировки** на текущем упражнении/сете, минуя Home и без вопросов. Таймер восстанавливается из сессии: остаток — если ещё идёт; отрицательное время — если истёк, пока страницы не было (**без** повторного звукового сигнала при восстановлении — пользователь и так смотрит на экран); остановленный — остаётся остановленным на своём значении.
- **Порог превышен или сутки сменились** → вопрос «продолжить / завершить». «Продолжить» → восстановление, как выше. «Завершить» → сессия закрывается **без** продвижения расписания (в гибриде та же тренировка предлагается снова как сегодняшняя).
- **Home при живой сессии** всегда показывает «продолжить» + прогресс (блоков сделано / всего), **никогда** «начать».

«N часов» — та же настройка, что и порог вопроса «продолжить/завершить» (`continueThresholdHours`); отдельного порога для восстановления нет.

## Перечень кейсов (проверочный список для реализации и тестов)

| Ситуация | Ожидаемое поведение |
| --- | --- |
| Записано сетов = цель, нажато «добавить» | Сет записан, блок открыт, «завершить» мигает |
| Суперсет A/B по 3, сделано A3 B3, «добавить» | Записывается A4, потом ожидается B4 (чередование продолжается) |
| Суперсет, «завершить» после A3 B2 | Блок закрыт целиком (B получил 2 сета) — это решение пользователя |
| Удалён последний сет блока | Счётчик и курсор откатываются на один сет назад |
| «Завершить» на последнем блоке | Сессия завершена, расписание продвинуто один раз, экран результата |
| Внеплановое в плановой сессии, «завершить» | Возврат к таймлайну на прежнюю позицию, курсор не двигался |
| Внеплановое без тренировки, «завершить» | Сессия (без плана) закрыта, Home в исходном состоянии |
| Внеплановое без тренировки — таймер | Есть, базовое значение = настройка по умолчанию |
| Таймер идёт, страница перезагружена через 20 с | Таймер показывает остаток минус 20 с, продолжает |
| Таймер `1:30` истёк, страница закрыта, открыта через 5 мин | Таймер показывает `-3:30` и тикает дальше; звука при открытии нет |
| Таймер в перерасходе, тап | Остановлен, показывает базовое `1:30` |
| Таймер остановлен, страница перезагружена | Остановлен, значение прежнее |
| Докрутка `+30` во время отсчёта | `endAt` +30 с, сигнал перепланирован |
| Сессия есть, открыто через 2 ч (порог 4 ч) | Сразу экран тренировки, без Home |
| Сессия есть, открыто через 6 ч | Вопрос «продолжить/завершить» |
| Сессия начата 23:30, открыто 00:30 при «начале суток» 04:00 | Сутки не сменились → сразу экран тренировки |
| Сессия начата 23:30, открыто 00:30 при «начале суток» 00:00 | Сутки сменились → вопрос «продолжить/завершить» |
| «Завершить» в вопросе продолжить/завершить | Сессия закрыта, расписание не продвинуто |
| Home открыт вручную при живой сессии | «Продолжить» + «блоков 2 / 5», кнопки «начать» нет |

## Рассмотренные альтернативы

- **Авто-завершение блока по цели** (Фаза 1) — лишает пользователя выбора «ещё сет или хватит»; отвергнуто.
- **Состояние таймера в компоненте** (Фаза 1) — теряется при выгрузке страницы; отвергнуто.
- **Остановка таймера на нуле** — скрывает, насколько затянулся отдых; отвергнуто в пользу отрицательного времени.
- **Звук при восстановлении, если `endAt` прошёл** — пугает без пользы, пользователь уже смотрит на экран; отвергнуто.
- **Внеплановое вне тренировки без сессии** (Фаза 1) — нет таймера и восстановления; отвергнуто, унифицировано через сессию без плана.
- **Отдельный порог для авто-восстановления** — лишняя настройка; используется общий N часов.

## Последствия

- Логика таймера и восстановления переезжает в ядро и покрывается тестами без DOM; отдельный DOM-тест компонента таймера не нужен.
- Модель `Session` расширяется состоянием таймера и допускает отсутствие плана.
- Home и роутинг при старте обязаны сначала проверить сессию в сейве.
- Ограничение платформы: если ОС выгрузила страницу, звук в момент `endAt` не прозвучит — компенсируется восстановлением с отрицательным временем и wake-lock.
