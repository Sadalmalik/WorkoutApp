# 09: Отчёты и графики прогресса

**What to build:** Просмотр прогресса по упражнению графиком, без внешних таблиц. Аналитика через сменные отчёты по [ADR 0002](../../../docs/adr/0002-report-abstraction.md).

**Blocked by:** 05, 02

**Status:** done

- [ ] Интерфейс отчёта (число линий, подписи, максимум шкалы линии, флаг раздельных графиков, значение(линия, точка)) + два отчёта: «макс. вес за день» и «макс. вес + повторы при нём»; для упражнений «вес тела» ключевая линия — повторы
- [ ] Выбор точки дня: максимальный по весу сет (при равенстве веса — с бо́льшими повторами); для «вес тела» — сет с макс. повторами. Покрыто тестами
- [ ] SVG-график в режиме по умолчанию: точки распределены по времени (мин. шаг 1 день), привязка к правому краю, скролл влево
- [ ] График показан на экране упражнения и на экране результата (личные рекорды вверху → сводка объём/сеты/длительность → список графиков с закреплёнными «далее/закрыть»)
- [ ] Детекция личных рекордов и сводка сессии покрыты тестами
