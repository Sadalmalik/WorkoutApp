# 04: Расписание, Home и запуск программы

**What to build:** Определение «что делать сегодня» и управление активной программой. Реализация обоих расписаний по [ADR 0001](../../../docs/adr/0001-scheduling-model.md) и машина состояний главного экрана.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Две реализации расписания (календарное, гибридное) за единым интерфейсом: текущая тренировка, продвинуть, пропустить, отложить, сериализация/десериализация состояния
- [ ] Гибрид: тренировка ждёт завершения, дни отдыха продвигаются по календарю. Календарь: неначатая пропущенная тренировка сгорает, «сегодня» = дата → день плана. Оба режима покрыты тестами (пропуск, возврат после перерыва, продвижение отдыха, pull-forward)
- [ ] Запуск программы через выбор программа + расписание (расписание по умолчанию — рекомендованное программой)
- [ ] Home отражает состояния (начать программу / отдых + начать следующую / тренировка + начать/пропустить / на паузе + продолжить / завершено + начать следующую); двойной тап Home открывает попап программы (пауза/отмена/смена); отмена возвращает Home в «начать программу»
- [ ] Кнопка «начать» ведёт на заглушку сессии (реальная сессия — тикет 05)
