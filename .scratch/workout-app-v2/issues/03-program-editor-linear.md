# 03: Редактор программ (линейный, один план)

**What to build:** Составление программы тренировок из одного плана линейным редактором, включая суперсеты и статические цели. Термины — по [CONTEXT.md](../../../CONTEXT.md).

**Blocked by:** 02

**Status:** done

- [ ] Создание программы с одним планом заданной длины в днях; каждый день — тренировочный или день отдыха
- [ ] Тренировка = упорядоченный список блоков; блок = одно или несколько упражнений + число сетов + интервал между сетами + интервал между упражнениями суперсета; блок с ≥2 упражнениями — суперсет
- [ ] У каждой записи упражнения в блоке — статическая цель (вес, повторы)
- [ ] У тренировки есть интервал между блоками; у программы — поле рекомендованного расписания
- [ ] В редакторе у упражнений видны зона и ссылки на видео (для продумывания программы)
- [ ] Построение/валидация модели программы покрыты тестами ядра
