# 12: Импорт и пайплайн мержа

**What to build:** Загрузка данных из файла без затирания и без дублей — двухпроходно: дедуп по именам, затем мерж с diff-сводкой.

**Blocked by:** 11

**Status:** done

- [ ] Проход 1 (дедуп): для каждого совпадения по имени приложение спрашивает «дубликат или разные сущности?»; при «разные» входящей сущности выдаётся новый `id` и перевязываются ссылки внутри импортируемого блока
- [ ] Проход 2 (мерж): diff-сводка с выбором политики на тип и индивидуально по элементу (пропустить / перезаписать / оставить оба; по умолчанию — пропустить существующие)
- [ ] Результаты и лог веса — union с дедупом по `(упражнение, метка времени, вес, повторы)`; настройки, состояние расписаний и сессия — заменяются входящими
- [ ] Round-trip экспорт→импорт, дедуп/перевязка и политики мержа покрыты тестами
