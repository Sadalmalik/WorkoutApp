# 01: Скелет приложения и префактор

**What to build:** Загружающаяся PWA-оболочка на месте v1. Удалить весь код интеграции v1 (Google Sheets/Forms, очередь). Заложить границу чистого TS-**ядра** с инъецируемыми портами `Clock` и `Storage` (адаптер localStorage + in-memory для тестов), тест-раннер, hash-роутер и оболочку с нижней навигацией на экраны-заглушки. Это фундамент, на котором стоят остальные тикеты. См. [CONTEXT.md](../../../CONTEXT.md).

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Код v1 (Google Sheets/Forms, queue-сервис) удалён; приложение собирается и грузится как устанавливаемая PWA с офлайн-оболочкой
- [ ] Ядро не импортирует React/DOM/localStorage; все эффекты идут через порты `Clock` и `Storage`; оба адаптера (localStorage, in-memory) реализованы
- [ ] vitest настроен; хотя бы один тест ядра зелёный на in-memory хранилище и фиксированных часах
- [ ] Нижняя навигация (Settings, Results, Home, вес тела, «+») переключает пять экранов-заглушек через hash-роуты; кнопки «назад/вперёд» браузера работают
- [ ] Тема следует светлая/тёмная/системная
