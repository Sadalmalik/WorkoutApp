# 11: Экспорт данных

**What to build:** Выгрузка данных в файл — для переноса на другое устройство и обмена программами. Определяет формат и `schemaVersion`, на которые опирается импорт (тикет 12).

**Blocked by:** 02, 03, 04, 05, 10

**Status:** ready-for-agent

- [ ] Полный экспорт: упражнения, мышцы, программы, результаты, лог веса тела, настройки, состояние расписаний, незавершённая сессия
- [ ] Экспорт «программы+упражнения»: программы (планы, блоки, цели), упражнения, на которые они ссылаются, мышцы этих упражнений и рекомендованное расписание — без результатов, веса тела, настроек и рантайм-состояния расписания
- [ ] Формат — JSON с полем `schemaVersion`
- [ ] Состав каждого режима экспорта покрыт тестами
