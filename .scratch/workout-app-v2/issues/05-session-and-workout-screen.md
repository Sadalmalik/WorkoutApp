# 05: Сессия и экран тренировки

**What to build:** Прохождение тренировки из конца в конец с персистентностью. Ядро сессии + экран тренировки без скролла страницы; таблица результатов и таймлайн — отдельные тикеты (06, 07), здесь базовый ввод. Сессия ортогональна расписанию (см. [ADR 0001](../../../docs/adr/0001-scheduling-model.md)).

**Blocked by:** 04

**Status:** done

- [ ] Старт сессии на сегодняшнюю тренировку; лог сетов (базовый ввод веса/повторов); завершение блоков; авто-завершение тренировки, когда все блоки сделаны
- [ ] Внеплановое упражнение через «+» становится активным, пишется в историю и не двигает курсор расписания; запущенное без активной тренировки — по завершении возвращает экран в исходное состояние
- [ ] Сессия переживает перезагрузку страницы и смену суток; вопрос «продолжить/завершить» появляется при смене суток или после N часов (из настроек) без залогированного сета; «завершить» закрывает прошлую сессию и предлагает сегодняшнюю тренировку
- [ ] По завершении расписание продвигается, поток идёт на базовый экран результата, затем в состояние «тренировка завершена»
- [ ] Экран тренировки — фиксированный вьюпорт без скролла страницы, регионы в согласованном порядке
- [ ] Жизненный цикл сессии, внеплановое упражнение и триггер «продолжить/завершить» покрыты тестами на фиксированных часах
