# 07: Виджет таймлайна тренировки

**What to build:** Обзор и управление позицией внутри тренировки внизу экрана.

**Blocked by:** 05

**Status:** done

- [ ] Таймлайн внизу: кружок = упражнение, блок = вертикальный столбик кружков, горизонтальная линия между столбиками = интервал между блоками
- [ ] Блок закрашивается целиком по завершении
- [ ] Отложить блок: он меняется местами со следующим блоком в таймлайне
- [ ] Запуск внепланового упражнения засеряет (приостанавливает) таймлайн текущей тренировки; возврат продолжает с прежней позиции
