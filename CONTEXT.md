# Workout App

Персональное веб-приложение (PWA) для показа тренировок и отслеживания силового прогресса. Данные хранятся локально в браузере; перенос между устройствами и обмен программами — через экспорт/импорт файлов.

## Язык

Терминология намеренно совпадает с общепринятой в силовых тренировках, чтобы понимать внешние источники и делиться программами с другими людьми.

### Каталоги

**Упражнение** (Exercise):
Конкретное движение (например, «Жим гантелей лёжа 30°»). Имеет зону, основную и вспомогательные мышцы, ссылки на видео, признак «вес тела» и свободные заметки. Живёт в каталоге независимо от программ.
_Avoid_: движение, activity

**Зона** (Zone):
Крупная область тела, к которой отнесено упражнение (Спина, Грудь, Бёдра, Пресс…). Свободный текст с автоподсказкой из ранее введённых значений. Грубая рубрика, в метриках не участвует.
_Avoid_: группа мышц, регион

**Мышца** (Muscle):
Запись в каталоге мышц: конкретная мышца с описанием и биологической базовой силой (заводится один раз извне). Упражнение ссылается на мышцы из каталога, у каждой ссылки — свой коэффициент вовлечённости (произвольное число 0..1, задаётся вручную; например, жим 45° — верхний пучок 1.0, средний 0.8, нижний 0.4). Даёт метрику баланса программы (подходов на мышцу за период, взвешенных коэффициентами).
_Avoid_: muscleGroup (термин v1, смешивавший зону и мышцу)

### Программа и её структура

**Программа** (Program):
Верхняя единица планирования. Содержит планы и паттерн ротации.
_Avoid_: routine

**План** (Plan):
Набор дней фиксированной длины; день — тренировочный или день отдыха. Программа состоит из одного или нескольких планов.
_Avoid_: week, mesocycle

**Ротация** (Rotation):
Упорядоченный список ссылок на планы, повторяющийся по кругу (например, План1–План1–План2). Простейшая программа — ротация из одного плана.

**День отдыха** (Rest day):
День плана без тренировки.

**Тренировка** (Workout):
Один тренировочный день плана. Упорядоченный список блоков; хранит интервал отдыха между блоками (`междуБлоками`). Это описание/план, а не факт выполнения (см. [[Сессия]]).
_Avoid_: session, day

**Блок** (Block):
Структурная единица тренировки. Содержит одно или несколько упражнений, число сетов, интервал между сетами (`междуСетами`) и интервал между упражнениями суперсета (`междуУпражнениямиСуперсета`). Блок с двумя и более упражнениями выполняется как суперсет.
_Avoid_: группа упражнений, set group

**Суперсет** (Superset):
Форма блока с двумя и более упражнениями: их сеты чередуются (A→B→A→B). Не отдельная сущность — определяется числом упражнений в блоке.

**Сет** (Set):
Одно выполнение упражнения: N повторений с заданным весом. Атомарная единица выполнения и записи результата. Синоним — «подход».
_Avoid_: rep-set

**Повторение** (Rep):
Одно повторение движения внутри сета.

### Выполнение и прогресс

**Расписание** (Scheduler):
Подключаемая стратегия, определяющая *как* используется программа: какая тренировка сейчас должна идти, как продвигается прогресс, как откладываются/пропускаются тренировки. Хранит собственное состояние отдельной структурой в сейве. Отделено от [[Программа|Программы]] (та — чистые данные). Программа несёт поле рекомендованного расписания; при запуске программы пользователь выбирает расписание (по умолчанию — рекомендованное). Реализации: календарное и гибридное (см. `docs/adr/0001-scheduling-model.md`).
_Avoid_: календарь, планировщик

**Сессия** (Session):
Выполнение тренировки в конкретную дату (текущее или историческое). Незавершённая сессия переживает смену суток (ночные тренировки).
_Avoid_: workout (это план), тренировка

**Результат** (Result):
Записанный факт выполнения сета: дата+время, упражнение, вес, повторы. Основа графиков прогресса (берётся максимальный по весу сет за день для упражнения).
_Avoid_: entry, лог

**Лог веса тела** (Bodyweight log):
Отдельные записи веса тела пользователя (вес + дата). Вес на момент тренировки = последняя запись с датой < даты тренировки.

**Отчёт** (Report):
Подключаемая стратегия, превращающая срез данных в линии графика: знает число линий, их подписи, максимум шкалы линии, флаг «раздельные графики стопкой ↔ одна общая ось», и вычисляет значение линии по точке данных. Точки данных произвольны (день упражнения, вес тела + тренировка, данные мышцы) — под каждый вид данных свои отчёты. Пользователь выбирает отчёт при открытом графике. Виджет графика — только отображение, метрика живёт в отчёте.
_Avoid_: график (это виджет), метрика

**Заметка** (Note):
Свободный текст, привязанный к сессии или дате («подскочило давление, закончил раньше»). Отдельный журнал + ввод во время тренировки. Функционал после Фазы 2.
